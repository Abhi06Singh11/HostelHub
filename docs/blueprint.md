# **App Name**: Vibe Focus

## Core Features:

- Real-time Clock Display: Continuously display the current time for quick reference.
- Focus Timer: A customizable timer (e.g., Pomodoro-style) with start, pause, and reset functions, indicating progress visually.
- Screen Wake Lock: Optionally keep the screen active during focus sessions to prevent interruptions, leveraging browser Wake Lock API.
- Focus Session Tracking: Track and display the number of completed focus sessions, stored client-side for immediate user feedback.
- Dynamic Focus Prompt Generator: A generative AI tool that provides short, context-aware prompts or task suggestions to help users initiate or maintain focus.
- Theme Customization and Toggling: Allow users to switch between light and dark modes and customize the primary and background colors to personalize their workspace.
- Simple Support/Feedback Form: Provide a simple client-side form for users to offer support or feedback, simulating a 'buy me a coffee' interaction.

## Style Guidelines:

- Primary color: A deep indigo (#4F46E5), evoking reliability and concentration. (HSL: 243, 75%, 61%)
- Background color: For light mode, a very subtle desaturated lavender-grey (#F3F3FA) provides a serene workspace. (HSL: 243, 15%, 95%)
- Accent color: A bright sky blue (#62D2FC) for calls to action and highlights, chosen for its energizing contrast. (HSL: 213, 80%, 70%)
- Headline font: 'Space Grotesk' (sans-serif) for a modern, tech-savvy and distinct look.
- Body font: 'Inter' (sans-serif) for its readability and clean, neutral appearance, complementing the headline font.
- Utilize clean, minimalist vector icons that align with a modern productivity tool aesthetic, consistent across themes.
- A clean, card-based layout centered around the focus timer, ensuring responsiveness across various screen sizes. Modals will be used for secondary interactions like customization.
- Implement subtle animations for UI transitions (e.g., modal opens, theme toggling) and progress indicators, such as the circular timer fill, to provide fluid user experience.
